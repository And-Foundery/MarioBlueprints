### B. Name it!
The kids love naming levels, so every idea card gets a **Name it!** area:

```
  Name it!  [ The Spooky Pizza Palace______ ]   (they type their own)

  Need help? Tap 3 tiles to build a name:
  [Spooky] [Giant] [Sneaky]   [Pizza] [Boo] [Rocket]   [Palace] [Dash] [Mayhem]
  [New tiles]
```

- Typing their own name comes first. The tiles are only there if they're stuck.
- The tiles match the idea. A Boo Race idea gets tiles like "Boo", "Haunted" and "Chase".
- They pick one tile from each row, so they still build the name themselves.
- The name is saved with the idea in My Ideas.

### C. Spin again vs. Mix it up (merged, so there's only one button)
They were confusing, so we keep **one big SPIN** and make the card's key words tappable:

> **Boo Race**: Race a line of <u>Boos</u> through a <u>haunted house</u>. Hit ON/OFF switches to open the path!

- **SPIN** gives a brand-new idea.
- **Tap a yellow word** to swap only that word. <u>Boos</u> can become <u>rising lava</u> or <u>Bullet Bills</u>, and <u>haunted house</u> can become <u>castle</u> or <u>volcano</u>. The rest of the idea stays the same.

Kids get to steer the idea themselves, which keeps it creative, and there's no second button to explain.

## 1. What the community says makes a level idea "click"

- **The best levels use one main idea again and again**, in new ways each time. A list of loose pieces isn't an idea.
- When makers run out of ideas, the usual advice is to pick a **kind** of level: a classic level, an auto level, a puzzle, a speedrun, a music level, a level made with only a few items, or a remake of a real Mario level.
- Common level types players talk about are auto levels, puzzle, speedrun, music, troll and "impossible" levels. **We drop troll and impossible levels** because they aren't fun for kids to build or share.
- Popular levels usually have one clear hook:
  - A Boo race built with ON/OFF switches
  - Sliding down a snowy mountain
  - A shell used as a ball
  - A two-screen "spot the difference" puzzle
  - Climbing an elevator tower with switches
- Nintendo's own lesson in the game (Yamamura's Dojo) says to jot the idea down on paper and split the level into sections.
- Another common tip: make it easier than you think, because you know the level and other players don't.

**What this means for us:** a kid needs *one sentence they can picture*, plus the few parts that make it work. The game style and the day/night choice are theirs to make.

## 2. The Idea Wheel (replaces the Spark Machine)

### How it works
1. A big wheel has **8 colored wedges**. Each wedge is a *kind* of level with its own icon.
2. Kids tap **SPIN**. The wheel spins and lands on a wedge.
3. An **idea card** flips over with a whole idea from that wedge.
4. On the card, they can:
   - **Spin again** for a new idea.
   - **Mix it up** to keep the idea but swap the place, the ride or the villain.
   - **Save** it to My Ideas.
   - **Read it to me** to hear it out loud.
5. They can also tap a wedge directly: "I want a Race idea."

```
            ┌──────── IDEA WHEEL ────────┐
            │        Ride    Escape      │
            │   Story   ╲    ╱   Puzzle  │
            │  ─────────( SPIN )──────── │
            │   Music   ╱    ╲   Race    │
            │       Boss    Treasure     │
            └────────────────────────────┘

   ┌───────────────────── IDEA CARD ─────────────────────┐
   │ [Escape icon]  ESCAPE!                               │
   │                                                      │
   │  "Boo Race"                                          │
   │  Race a line of Boos through a haunted house.        │
   │  Hit ON/OFF switches to open the path before         │
   │  they catch you!                                     │
   │                                                      │
   │  Parts you'll need:  [Boo] [ON/OFF Switch]           │
   │                      [Dotted-Line Block] [Door]      │
   │                      (tap a part to open the book)   │
   │                                                      │
   │  [Spin again]  [Mix it up]  [Save]  [Read it to me]  │
   └──────────────────────────────────────────────────────┘
```

The card is **short**: a name, one or two sentences, and 3–4 parts. It gives no steps, and the kids build it their own way.

### How we get thousands of *whole* ideas (not loose pieces)
- We write about **15 hand-made ideas per wedge**, so 120 in total.
- Each idea has **swappable words** that still make sense. For example, the chaser in "Escape" can be lava, poison or a Boo swarm, and the place can be a castle, a volcano or a haunted house. Each idea has about 20–40 good versions.
- 120 ideas × about 30 versions ≈ **3,600 whole ideas**. **Mix it up** moves between those versions.
- An optional **Add a twist** button puts one fun change on top, such as "...but it all goes UP" or "...and it's in the dark". Each idea works with about 10 twists, so there are **30,000+ combinations**.
- Each idea records which game styles it works in, so the card never suggests something the game can't do.

## 3. Music: easier for kids

**Problem:** rows, tiles, a table and settings are too much at once for this age.

**New flow: Listen → Build-Along → Play it**

1. **How it works: 3 picture cards, one sentence each**
   - "Put a Note Block. Drop a Goomba on it. Now it sings!"
   - "Higher block = higher note."
   - "Turn on auto-scroll. The song plays as the screen moves."
2. **Pick a song.** There are big picture buttons for 7 songs, and each one plays as a preview.
3. **Build-Along mode** (the main change). It shows **one block at a time**, like LEGO instructions:
   ```
   ┌──────── Block 3 of 14 ────────┐
   │   [mini picture of your level] │
   │   ▇        ▇                   │
   │   ▇   ▇   [▇] ← put it here    │
   │                                │
   │   Go RIGHT 2 ➜    Go UP 4 ⬆    │
   │     [Hear this note]           │
   │   [◀ Back]         [Next ▶]    │
   └────────────────────────────────┘
   ```
   - Each step says only "**right X, up/down Y**" from the last block. Kids don't count rows from the bottom.
   - The note plays each time they tap Next, so they hear the song grow.
   - A progress bar fills up with stars.
4. **Test it.** A short checklist: "Did you turn on auto-scroll? Too fast? Try Slow."
5. **Make your own tune.** It keeps the tap grid, cut down to **8 rainbow notes × 8 steps** with bigger squares. Then it opens in Build-Along mode too.

Grown-up settings (start row, spacing) go behind a small **Grown-ups** button.

## 4. Parts Book: accuracy plan

Every part gets a record like this:

```
name (exact in-game name) · category (Terrain / Items / Enemies / Gizmos)
game styles it appears in · what it does (one kid sentence) · music sound (only if known)
checked: yes / not yet
```

**Already confirmed from sources**
- Goomba's Shoe: only in SMB and SMB3. Yoshi's Egg: only in SMW and NSMBU.
- Clear Pipes, the Koopa Troopa Car and Blinking Blocks: only in 3D World.
- Night isn't available in 3D World.
- Music Blocks: height sets the note (one block up = a half step). The object you drop sets the sound: Goomba is piano, Super Mushroom is an 8-bit beep, Bowser Jr. is saxophone, Koopa Clown Car is synth. In tall areas the notes start over every 28 rows.

**Still to check**

3D World has its own parts list, so parts like Wings, Track, Vine, Seesaw, Swinging Claw, Cannon and Snake Block need checking there. The mockup said "All game styles" for these, which may be wrong. Nothing ships marked as checked until it has been checked.

**How we check** (either works):
- **Part Detectives:** the kids open 3D World style in the game, look through the parts menu and tick a checklist on the site. It's a fun job for them.
- Open network access to `supermariomaker2.fandom.com` and `www.mariowiki.com` so Claude can check against the wikis.
