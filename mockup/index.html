How Music Blocks work

Four steps. Every note in a song is built the same way.

1

Make a Music Block. Press and hold the Note Block, then pick the Music Block.

2

Add a Cloud Block on top, and put a Goomba inside the cloud. It drops, plays one note, and stays on the cloud.

3

Higher block = higher note. Each square up is one step higher.

4

Turn on auto-scroll. Each Goomba drops when the screen reaches it, so the song plays as you move.

Try one note first! Build just one Music Block + Cloud + Goomba, then press play. When you hear it, you're ready for a whole song.

Build a song, like pixel art

Pick a song. Then copy the picture into your level, square by square. Each colored square is one Music Block.

1. Pick a song

2. Copy the picture

3. Finish and test

Not working? No sound: check it's a Music Block, not a Note Block. Extra notes: the Goomba walked off the cloud, so put a block on each side of it like a little cage. Too fast: leave more squares between the blocks.
Grown-ups: settings

In the game, songs are played by moving the screen at a steady speed. Change the squares per beat if the song sounds too fast or too slow.

Make up your own tune
